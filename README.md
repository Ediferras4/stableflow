# StableFlow

StableFlow is a demo payment dApp focused on simple QR payments and token-to-stable payment flow.

The idea is simple: the payer can use the token they have, while the receiver gets stable value.

## Demo

Live demo: https://stableflow-ten.vercel.app/

## What it does

- Connects a wallet
- Shows a payment-focused interface
- Supports QR payment flow
- Demonstrates token-to-stable payment logic
- Focuses on a simple user experience for testnet payments

## Project goal

StableFlow is being built as a payment experiment for Web3 users who want a cleaner and easier way to send or request payments.

Instead of making the receiver worry about token volatility, the app is designed around a simple concept:

> The payer uses the token they have, and the receiver gets stable value.
